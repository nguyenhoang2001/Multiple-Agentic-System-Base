# Smart Home Agent Demonstration Examples
# These examples show how the agent interprets user requests and maps them to device commands.
# Available devices: light_living_01 (living room), light_bedroom_01 (bedroom), thermostat_01 (bedroom)

---

## Example 1: Turn on the living room light
User: "Turn on the lights in the living room"
Reasoning: User wants light_living_01 enabled. No specific brightness mentioned — use default 80%.
Command: POST /api/devices/light_living_01/control {"action": "turn_on", "brightness": 80}
Response: "Living room light turned on at 80% brightness."

---

## Example 2: Turn off the bedroom light
User: "Turn off the bedroom light"
Reasoning: User wants light_bedroom_01 turned off.
Command: POST /api/devices/light_bedroom_01/control {"action": "turn_off"}
Response: "Bedroom light turned off."

---

## Example 3: Set a comfortable temperature
User: "It's too cold, make it warmer"
Reasoning: User wants temperature raised. Set thermostat to comfort default of 22°C.
Command: POST /api/devices/thermostat_01/control {"action": "set_temperature", "setpoint": 22, "mode": "heat"}
Response: "Thermostat set to 22°C in heating mode."

---

## Example 4: Check the thermostat
User: "What's the temperature in the bedroom?"
Reasoning: Retrieve the current reading from thermostat_01.
Action: Query thermostat_01 sensor data for current temperature.
Response: "The bedroom temperature is currently 21.3°C."

---

## Example 5: Turn off everything before bed
User: "I'm going to bed, goodnight"
Reasoning: User wants to turn off all lights and lower the temperature.
Commands:
  POST /api/devices/light_living_01/control {"action": "turn_off"}
  POST /api/devices/light_bedroom_01/control {"action": "turn_off"}
  POST /api/devices/thermostat_01/control {"action": "set_temperature", "setpoint": 19, "mode": "auto"}
Response: "Goodnight! Lights off and thermostat set to 19°C."

---

## Example 6: Set a scene
User: "Movie time"
Reasoning: Movie scene typically means dimmed warm lights in the living room.
Command: POST /api/devices/light_living_01/control {"action": "set", "brightness": 20, "color_temperature": 2700}
Response: "Movie mode activated: living room light dimmed to 20% warm white."

---

## Example 7: Adjust brightness
User: "Make the bedroom light brighter"
Reasoning: User wants to increase brightness on light_bedroom_01.
Command: POST /api/devices/light_bedroom_01/control {"action": "set", "brightness": 100}
Response: "Bedroom light set to 100% brightness."
